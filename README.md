# Planet-Scale Internet Outage Prediction Simulator

A terminal-based simulator that models internet topology and injects outages to simulate cascading failure scenarios. Using classical AI, it also identifies potential vulnerabilities using betweenness centrality and Dijkstra search.

## Features
- Real global internet topology mapped to 6 major regions
- Discrete event simulator with full chronological output
- Dynamic ASCII world map rendered live
- Dijkstra-based routing evaluation
- Cascading failure simulations
- Rule-based expert system vulnerability reports

## Compilation & Run
```bash
make
make run
# or
./simulator
```
